MOD>PORTER

Drop in a zip of Minecraft mods, pick a game version and loader, and get back the same mods rebuilt for that target — fetched from Modrinth, with CurseForge as the fallback. Mods with no matching build are skipped.

Can't reach the mod databases from here. If you're viewing this inside a sandboxed preview (like Claude), download this file and open it in your browser — it runs entirely on your machine.

INPUT

Drop a mods .zip or click to browse — loose .jar files work too

TARGET

CurseForge API key (optional)

Without a key, CurseForge lookups go through the public curse.tools mirror, which can be slow or down. Free keys: console.curseforge.com

OUTPUT

Your rebuilt zip lands here.

Mods are matched first by file hash on Modrinth, then by name; anything left over is looked up on CurseForge by fingerprint, then by name. Files download straight from the official CDNs.

    
Mods whose authors turned off third-party downloads (or whose CDN blocks in-page fetches) get a manual download link instead of being packed into the zip. Name-based matches are best-effort — double-check anything marked “name match”.
